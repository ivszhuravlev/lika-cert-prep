## 3. Бот

**Работает.** Pure stdlib, 20 тестов на Python 3.9. Прогон реального `handle()` по 45 модулям и всем режимам: 9307 сообщений, 0 исключений, ни одного >4096. Живая отправка тяжёлых кейсов — все 200 OK. Поднят под launchd (`~/Library/LaunchAgents/com.lika.certbot.plist`, лог `progress/bot.log`). Входящие проверяются только с живым пользователем.

Критично:
- `bank.py:111–134` `_lesson_chunks` выбрасывает все секции вне трёх групп: бот не показывает 18 % теории (m38 62 %, m22 60 %, m21 56 %, m36 42 %). Gap Tutorial обрывается после «Given.».
- `bank.py:83–96` `parse_number`: `1,5`→1.0, `1 500`→1.0, `1.5e3`→1.5, `.5`→5.0; распознанное число не показывается.
- `engine.py:69` `problems()`: 39 из 446 задач с текстовым ключом (Co-60 → −60, A0/λ → 0).
- `engine.py:76` `close_enough` 2 %/0.01 — 93 задачи, где дистрактор в допуске.

RU-режим: `_same_english` True для строк без букв → 534 числовых варианта с префиксом «Перевод не получился»; «cm»→«см» и «3.5»→«3,5» отбраковываются; «mu» как подстрока — ~9 % ложных; Ollama qwen2.5:3b синхронно в poll-цикле, 5+ вызовов на вопрос, переводы местами неверны.

Надёжность: `except`-ветка `main` шлёт без защиты (429/сеть роняют процесс до save → повтор сообщения); нет retry_after, тело HTTPError не читается; JSON без tmp+rename; `load_modules()` на каждое сообщение; нет whitelist chat_id.

Визуально: квиз/задача/разбор чисто; таблицы, `**`, `#`, LaTeX сырым текстом; два сообщения на блок теории; вход в теорию всегда с блока 1; «вместе» пропускает остаток многостраничного абзаца; цифра в задачах засчитывается как ответ; `/help` = список; нет итогов; колода не перемешивается; «в дорогу» показывает ответы до копирования.

Порядок: 1) `_lesson_chunks`; 2) `parse_number` + эхо; 3) фильтр `problems()`; 4) защита `except`/`call`, атомарная запись; 5) RU-guard; 6) один message на блок + продолжение; 7) таблицы/LaTeX → plain text; 8) кэш модулей, whitelist, таймстемпы.

## Итог / вердикт

**Not ready.** Банк хорош как тренажёр ручной арифметики (домены I, IV, частично V) и содержит несколько очень качественных модулей с «клиническим суждением» (m19, m25, m18/m32). Но для экзамена, где 42 % — Treatment Planning, а значительная часть вопросов — работа с изображением/планом (ProKnow, head-first supine CT), банк имеет три структурных дефекта:

1. **Распределение не соответствует блюпринту.** Домен III (42 %) покрыт 372 вопросами из 1393 (27 %), а домен IV (13 %) — 332 (24 %). Домен VI — 3,4 %, VII — 4,7 % против 9 % каждый.
2. **Половина численных задач «подсказана»**: из 598 численных вопросов у 300 формула написана прямо в условии (`MU = dose / (...)`, `Skin gap = (L1/2)×(d/SSD1)+…`). На экзамене формул нет. ~207 вопросов в m33–m42 — вариации одного шаблона (разные числа, один и тот же текст рационале).
3. **Системная физическая ошибка** в breast-matching (couch kick ↔ collimator), причём внесённая как «исправление» предыдущим ревью (`knowledge/review/exam-readiness.md:34`).

Оценка готовности по доменам (ниже) даёт взвешенно ≈ **54 %**. Кандидат, прошедший весь банк, уверенно наберёт домены I и IV, но «провалит» site-specific planning, SBRT-констрейнты, анатомию по изображениям, регуляторику NRC и QA-толерансы.

## Оценка practice exams (m44)

- Формат: 2 формы × 40 вопросов + 5 вопросов про формат = 85 (`knowledge/questions/m44-practice-tests.md`). Реальный экзамен — 155 вопросов, 230 мин, ~130 засчитываемых. **Нет ни одной формы полной длины**; невозможно отработать темп (≈ 1,5 мин/вопрос).
- Доменный микс обеих форм идентичен: I 6, II 2, III 17, IV 5, V 2, VI 4, VII 4. Цель на 40: I 5,6 / II 3,2 / III 16,8 / IV 5,2 / V 2 / VI 3,6 / VII 3,6 — совпадает, кроме Localization (2 вместо 3).
- **Репрезентативность сложности — низкая.** 28 из 49 численных вопросов содержат формулу в stem; все численные задачи — те же шаблоны, что в модулях (decay, HVL, ISL, MU с данными факторами, Mayneord, gap, eq-square, wedge-left-in, permanent implant, Γ). Ни одного вопроса с изображением, с чтением плана/DVH по таблице, с анатомическим срезом, с site-specific выбором техники. Качественные вопросы (PE1 Q34–40, PE2 Q34–40) — хорошие, но их ~7 на форму.
- Ошибки в формах: PE2 Q10 и Q40 (couch/collimator инверсия, см. выше); «The Format» Q1–Q5 тегированы III.1.
- Вывод: формы годятся как «mixed drill», но **не как имитация экзамена**. Нужна хотя бы одна форма на 155 вопросов с таймером, где ≥ 60 % вопросов — без формулы в условии и ≥ 25 — по изображениям/планам.
