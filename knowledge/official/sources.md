# Sources

Read 2026-10-10. Public MDCB and AAPM pages only. No PDF files are stored in this repo.

The January 2027 applicant handbook is the current exam document. The applicant-handbook page links two files, `Exam Handbook_2027.1_final_1.pdf` and `Exam Handbook_2027.1_final_0.pdf`. Both open as the January 21–23, 2027 session. Extracted text differed by line-break spacing. Notes use `final_1`.

`Exam Handbook_2026.9_final.pdf` is the earlier September 17–19, 2026 session. Where the two handbooks or a live page disagree, the later document is named in the note that uses the fact.
